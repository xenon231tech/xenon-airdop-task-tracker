# 🤝 Contributing to Xenon Airdrop Tracker

Terima kasih sudah mau berkontribusi! 🎉

---

## Cara Berkontribusi

### 1. Fork Repository
Klik tombol **Fork** di pojok kanan atas.

### 2. Clone hasil fork
```bash
git clone https://github.com/username-anda/xenon-airdrop-task-tracker.git
cd xenon-airdrop-task-tracker
git checkout -b fitur/nama-fitur
git add .
git commit -m "feat: deskripsi singkat"
4. Scroll ke bawah, isi **Commit message**: `docs: upgrade CONTRIBUTING.md`

5. Klik hijau **Commit changes**

---

## ✅ Selesai!

File `CONTRIBUTING.md` lo sekarang sudah upgrade dan lebih lengkap! 🔥
