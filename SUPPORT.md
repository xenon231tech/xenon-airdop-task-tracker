## Common Issues & Solutions

### Issue: Tasks Not Saving

**Solution**:
1. Check if localStorage is enabled
2. Clear browser cache
3. Try incognito mode
4. Try different browser

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md#tasks-not-saving) for details.

### Issue: Charts Not Displaying

**Solution**:
1. Refresh the page
2. Check browser console for errors
3. Ensure JavaScript is enabled
4. Try different browser

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md#charts-not-displaying) for details.

### Issue: Search Not Working

**Solution**:
1. Check search term spelling
2. Verify tasks exist
3. Clear search field
4. Refresh page

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md#search-not-working) for details.

### Issue: Import Not Working

**Solution**:
1. Check file format (must be JSON)
2. Verify file size
3. Try different file
4. Check browser console

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md#import-not-working) for details.

## Performance Issues

### Slow Loading

**Causes**:
- Slow internet connection
- Browser cache issues
- Browser extensions
- Device resources

**Solutions**:
1. Check internet speed
2. Clear browser cache
3. Disable extensions
4. Close other applications

### Slow Search/Filter

**Causes**:
- Too many tasks
- Browser performance
- Device resources

**Solutions**:
1. Reduce task count
2. Archive old tasks
3. Restart browser
4. Update browser

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md#performance-issues) for details.
