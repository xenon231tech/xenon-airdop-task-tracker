# Examples & Tutorials

## Getting Started Examples

### Example 1: Creating Your First Task

**Step 1**: Open the application at https://xenon-airdop-task-tracker.vercel.app/

**Step 2**: Fill in the task form:
- Task Name: "Complete KYC Verification"
- Category: "DeFi"
- Priority: "High"
- Deadline: "2024-06-15"
- Project Link: "https://example.com/kyc"

**Step 3**: Click "Add Task"

**Step 4**: Task appears in the list with a success notification

---

### Example 2: Filtering Tasks

**By Category**:
1. Click "Filter by Category" dropdown
2. Select "DeFi"
3. Only DeFi tasks are shown

**By Status**:
1. Click "Filter by Status" dropdown
2. Select "Pending"
3. Only pending tasks are shown

**By Search**:
1. Type "KYC" in search box
2. Tasks matching "KYC" are shown
3. Clear search to reset

---

### Example 3: Sorting Tasks

**Available Sort Options**:
- Newest First - Most recently added tasks first
- Oldest First - Oldest tasks first
- Priority - High priority tasks first
- Deadline - Earliest deadline first

**How to Sort**:
1. Click "Sort By" dropdown
2. Select sort option
3. Tasks are reordered automatically

---

### Example 4: Exporting Your Data

**Export as JSON**:
1. Click "Export" button
2. JSON file downloads automatically
3. Save it to your computer
4. Use for backup or sharing

**JSON Format**:
```json
{
  "tasks": [
    {
      "id": "1",
      "name": "Complete KYC",
      "category": "DeFi",
      "priority": "High",
      "deadline": "2024-06-15",
      "link": "https://example.com/kyc",
      "completed": false,
      "createdAt": "2024-06-04T10:00:00Z"
    }
  ]
}
```

---

### Example 5: Importing Data

**From JSON File**:
1. Click "Import" button
2. Select JSON file from computer
3. Tasks are imported automatically
4. Existing tasks are merged

**Supported Format**:
```json
{
  "tasks": [
    {
      "name": "Task Name",
      "category": "Category",
      "priority": "Priority",
      "deadline": "YYYY-MM-DD",
      "link": "https://...",
      "completed": false
    }
  ]
}
```

### Example 6: Using Keyboard Shortcuts

**Available Shortcuts**:
- `Ctrl + N` - Focus on task name input
- `Escape` - Clear search filter
- `Enter` - Submit form (when focused)

**How to Use**:
1. Press `Ctrl + N` to focus on input
2. Type task name
3. Press `Tab` to move to next field
4. Press `Enter` to submit

## Troubleshooting Examples

### Issue 1: Data Not Saving

**Solution**:
1. Check browser storage is enabled
2. Clear browser cache
3. Refresh page
4. Try again

---

### Issue 2: Export Not Working

**Solution**:
1. Check file format
2. Verify JSON is valid
3. Try different browser
4. Check console for errors

---

### Issue 3: Import Failed

**Solution**:
1. Verify JSON format
2. Check file encoding (UTF-8)
3. Validate JSON structure
4. Try smaller file first
