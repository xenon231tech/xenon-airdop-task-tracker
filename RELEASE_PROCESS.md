# 🚀 Release Process

## Versioning

Format: **MAJOR.MINOR.PATCH**

| Jenis | Contoh | Kapan |
|-------|--------|-------|
| **Major** | 1.0.0 → 2.0.0 | Breaking changes (ubah struktur data) |
| **Minor** | 1.0.0 → 1.1.0 | Fitur baru (tambah kolom, fitur) |
| **Patch** | 1.0.0 → 1.0.1 | Bug fix (perbaikan error) |
