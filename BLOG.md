# 📝 Xenon Airdrop Task Tracker - The Story

## Why I Built This

Sebagai hunter airdrop, saya sering ketinggalan tugas. Jadi saya buat tools ini.

## Features That Matter

1. **Task Management** - Simpan semua tugas airdrop
2. **Categories** - DeFi, NFT, L1, L2, GameFi
3. **Priority System** - High/Mid/Low
4. **Dark Mode** - Nyaman dipakai malam
5. **Export/Import** - Backup data

## Tech Stack

- HTML5 + CSS3 + Vanilla JS
- Chart.js untuk grafik
- LocalStorage untuk data
- GitHub Pages + Vercel untuk hosting

## What's Next?

- Wallet Connect integration
- Push notifications
- Mobile app

## Lessons Learned

- LocalStorage is powerful
- Dark mode improves UX
- Export feature is must-have
