# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | ✅                 |
| < 1.0   | ❌                 |

## Reporting a Vulnerability

Jika Anda menemukan celah keamanan, **JANGAN** buka issue publik.

Silakan laporkan ke:

📧 **Email:** xannrlcs@gmail.com

**Informasi yang harus disertakan:**
- Deskripsi celah keamanan
- Langkah-langkah mereproduksi
- Dampak potensial
- Saran perbaikan (jika ada)

Laporan akan ditanggapi dalam **48 jam**.
