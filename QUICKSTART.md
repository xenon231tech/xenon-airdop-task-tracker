# Quick Start Guide

## 🚀 Get Started in 2 Minutes

### Step 1: Open the App

Visit: **[xenon-airdop-task-tracker.vercel.app](https://xenon-airdop-task-tracker.vercel.app)**

That's it! No installation needed.

---

## 📝 Add Your First Task

### Method 1: Using the Form

1. Click **"+ Add Task"** button
2. Fill in the details:
   - **Task Name**: What you need to do (e.g., "Complete KYC")
   - **Category**: Select from DeFi, NFT, L1, L2, GameFi, SocialFi
   - **Priority**: High, Medium, or Low
   - **Project Link**: URL to the project
   - **Deadline**: When it's due
   - **Description**: Additional notes
3. Click **"Add Task"**
4. See success notification ✅

### Method 2: Quick Add (Keyboard)

1. Press **Ctrl + N** to focus the input
2. Type task name
3. Press **Enter**
4. Fill in remaining details

---

## 🔍 Find Your Tasks

### Search

1. Type in the **Search** box
2. Results update in real-time
3. Press **Esc** to clear

### Filter by Category

1. Click **"Filter by Category"**
2. Select a category (DeFi, NFT, etc.)
3. See only tasks in that category

### Filter by Status

1. Click **"Filter by Status"**
2. Choose "Completed" or "Pending"
3. View filtered tasks

### Sort Tasks

1. Click **"Sort By"**
2. Choose: Newest, Oldest, Priority, or Deadline
3. Tasks reorder automatically

---

## ✅ Mark Tasks Complete

### Complete a Task

1. Find the task in the list
2. Click the **"✓"** button
3. Task moves to completed section
4. See the checkmark ✅

### Undo Completion

1. Click the task's **"✓"** button again
2. Task returns to pending

---

## 📊 View Analytics

### Charts

1. Scroll to **"Analytics"** section
2. See task distribution by category
3. Click **"Chart Type"** to change view:
   - Doughnut (default)
   - Bar chart
   - Line chart
4. Hover over chart for details

### Statistics

View at the top:
- **Total Projects**: Number of tasks
- **Completed**: Finished tasks
- **Pending**: Remaining tasks

## 💾 Backup Your Data

### Export Tasks

1. Click **"Export"** button
2. JSON file downloads automatically
3. Save it somewhere safe
4. This is your backup!

### Import Tasks

1. Click **"Import"** button
2. Select your JSON file
3. Tasks restore immediately
4. Perfect for switching devices

## 🆘 Quick Troubleshooting

### Tasks Not Saving?
- Check if localStorage is enabled
- Try clearing browser cache
- Try a different browser

### Search Not Working?
- Check your search term spelling
- Make sure tasks exist
- Try refreshing the page

### Charts Not Showing?
- Refresh the page
- Check browser console (F12)
- Try a different browser

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for more help.

## 🎯 Best Practices

### Organization Tips

1. **Use Categories**: Group similar tasks
2. **Set Priorities**: Know what's urgent
3. **Add Deadlines**: Stay on track
4. **Write Descriptions**: Remember details
5. **Regular Backups**: Export weekly

### Workflow Tips

1. **Start Small**: Add 3-5 tasks first
2. **Review Daily**: Check pending tasks
3. **Complete Tasks**: Mark when done
4. **Archive Old**: Keep list clean
5. **Export Often**: Backup regularly
