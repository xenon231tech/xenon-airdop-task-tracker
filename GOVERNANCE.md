# 🏛️ Project Governance

## Decision Making

### Small Changes
- Pull Request dengan 1 approval langsung merge

### Medium Changes
- Minimal 2 approval atau 3 hari diskusi

### Major Changes
- Perlu diskusi via Issue
- Minimal 1 minggu feedback period

## Roles

| Role | Responsibilities |
|------|------------------|
| **Lead Maintainer** | Final decision, security |
| **Maintainers** | Review PR, respond to issues |
| **Contributors** | Submit PR, report bugs |
