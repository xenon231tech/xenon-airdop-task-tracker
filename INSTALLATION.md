## 💻 Local Installation

### Requirements
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (optional, for modifications)
- Git (optional, for cloning)

### Method 1: Download ZIP

1. Go to [GitHub Repository](https://github.com/xenon231tech/xenon-airdop-task-tracker)
2. Click **"Code"** → **"Download ZIP"**
3. Extract the ZIP file
4. Open `index.html` in your browser

### Method 2: Git Clone

```bash
# Clone the repository
git clone https://github.com/xenon231tech/xenon-airdop-task-tracker.git

# Navigate to directory
cd xenon-airdop-task-tracker

# Open in browser
open index.html
```

### Method 3: Using a Local Server

For better development experience, use a local server:

#### Using Python
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

#### Using Node.js
```bash
# Install http-server globally
npm install -g http-server

# Run server
http-server
```

#### Using Live Server (VS Code)
1. Install "Live Server" extension in VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"

## 🚀 Getting Started

### First Time Setup
1. Open the application
2. Click **"+ Add Task"** button
3. Fill in your first airdrop task
4. Click **"Add Task"** to save

### Basic Workflow
1. **Add Tasks** - Create tasks with categories and priorities
2. **Search & Filter** - Find tasks quickly using search
3. **Track Progress** - Mark tasks as completed
4. **View Analytics** - Monitor your progress with charts
5. **Export Data** - Backup your tasks as JSON

## 💾 Data Storage

Your data is stored locally in your browser using **localStorage**:
- ✅ Data persists across sessions
- ✅ No account needed
- ✅ Private and secure
- ⚠️ Clearing browser data will delete tasks
- 💡 Use Export feature to backup

---

## 🔧 Troubleshooting

### Tasks Not Saving?
- Check if localStorage is enabled in browser
- Try clearing browser cache
- Use a different browser

### Charts Not Displaying?
- Ensure JavaScript is enabled
- Check browser console for errors
- Try refreshing the page

### Performance Issues?
- Close other browser tabs
- Clear browser cache
- Use a modern browser version
