# ❓ Frequently Asked Questions (FAQ)

## Umum

### Q: Website ini gratis?
**A:** Ya, 100% gratis dan open source!

### Q: Data saya disimpan di mana?
**A:** Data tersimpan di **localStorage browser** Anda. Tidak ada server, jadi aman.

### Q: Bisa pakai di HP?
**A:** Bisa! Website sudah responsive dan support semua device.

---

## Teknis

### Q: Bagaimana cara menghapus semua data?
**A:** Buka DevTools (F12) → Application → Local Storage → Hapus item `xenon_tasks`

### Q: Bisa export data ke Excel?
**A:** Bisa! Klik tombol **CSV** → buka file dengan Excel.

### Q: Apada data bisa hilang?
**A:** Data aman selama Anda tidak hapus local storage browser.
