# Frequently Asked Questions

## General Questions

### What is XENON AIRDROP ULTIMATE?

XENON AIRDROP ULTIMATE is an advanced task tracker designed specifically for managing airdrop tasks. It helps you organize, track, and manage all your airdrop opportunities in one place with a vibrant, neon-themed interface.

### Is it free?

Yes! XENON AIRDROP ULTIMATE is completely free and open-source. No hidden fees or premium tiers.

### Do I need to create an account?

No account required! Everything works locally on your device with no login needed.

### Is my data safe?

Yes. All your data is stored locally in your browser. It never leaves your device or goes to any server.

## Data Management

### How do I backup my data?

Click the "Export" button to download your tasks as a JSON file. Keep this file safe!

### How do I restore from backup?

Click "Import" and select your previously exported JSON file. Your tasks will be restored.

### What happens if I clear my browser cache?

All data will be deleted. This is why regular backups are important!

### How do I move data to another device?

1. Export data on device 1
2. Open the app on device 2
3. Import the exported file
4. Your tasks will appear on device 2

### Can I sync across multiple devices?

Not automatically, but you can manually export/import to keep devices in sync.

### How much data can I store?

Browser localStorage typically allows 5-10 MB. This is enough for thousands of tasks.

## Performance & Optimization

### Why is it slow?

Possible causes:
- Too many tasks (try archiving old ones)
- Browser has many extensions
- Device is low on memory
- Internet connection is slow

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for solutions.

### How do I improve performance?

1. Archive old tasks
2. Disable browser extensions
3. Clear browser cache
4. Use a modern browser
5. Close other applications

### What's the load time?

Typically under 1 second on modern connections.

### Does it work on slow connections?

Yes, the file is only 36 KB, so even slow connections load it quickly.

## Troubleshooting

### Tasks are not saving

Check if localStorage is enabled in your browser. See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for detailed solutions.

### Search is not working

Try refreshing the page. Make sure your search term matches task names or descriptions.

### Charts are not showing

Try refreshing the page. Check your browser console (F12) for errors.

### Import is not working

Make sure the file is valid JSON format. Try exporting a fresh file to test.

### The app is not loading

Try clearing browser cache and refreshing. Disable extensions and try again.
