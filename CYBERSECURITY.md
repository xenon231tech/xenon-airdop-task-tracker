# 🔒 Cybersecurity Guidelines

## Best Practices

### Untuk User
- Jangan bagikan data pribadi di catatan tugas
- Gunakan password manager untuk wallet
- Verifikasi URL sebelum connect wallet

### Untuk Developer
- Jangan commit API keys atau private keys
- Gunakan environment variables
- Update dependencies secara rutin
